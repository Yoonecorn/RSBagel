# Security policy

Do not open a public issue for an undisclosed vulnerability or a scientific-correctness problem whose disclosure could cause users to rely on incorrect output. While the repository is private, contact the maintainers through your existing private access. Do not include restricted datasets in reports.

GitHub private vulnerability reporting is planned for public launch. After publication, use the repository's Security tab and **Report a vulnerability** once that option has been enabled and verified. No response time is promised.
