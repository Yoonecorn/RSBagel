# Security policy

GitHub private vulnerability reporting is enabled. For an undisclosed security vulnerability or a scientific-correctness issue whose disclosure could cause users to rely on incorrect output, use [Report a vulnerability](https://github.com/Yoonecorn/RSBagel/security/advisories/new) on the repository’s Security tab.

Do not open a public issue for an undisclosed vulnerability or include restricted datasets in a report. No response time is promised.
