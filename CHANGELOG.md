# Changelog

## v1.0.0 — release candidate

- First qualified RSBagel release candidate for the evaluated Apple Silicon macOS source configuration, preserving the bounded BAGEL2 scientific contract.
- Provides `fc`, `bf`, and `pr` through a CLI, Rust API, and C ABI.
- Includes the NumPy-compatible production profile, deterministic experimental native ChaCha8, and replay from supplied partitions.
- Includes a synthetic beginner example, user documentation, a developer guide, and manuscript.
- Other platforms and native ChaCha8 are not qualified; performance and memory use vary by workload. Computational agreement does not establish biological validity.
